ui-filter

A button that opens a panel of tickable answers, grouped under the question they answer, with Clear and Done at the foot. Every group is a set — nothing ticked means "do not narrow by this", so there is no All row. Add single for the rare filter that genuinely admits one answer, and <ui-filter-fields> for the things a tick cannot say: a date range, an MRN.

It reports ui-filter-change on every tick and ui-filter-apply on Done, both carrying the whole state as { group: [value, …] } — which admits() in js/lib/filter-set.js reads directly. The badge counts the ticks plus any contributed field that has something in it.

ui-icd10

One control for every ICD-10 field in the app. Searches the code and the description together — K21, K219 and reflux all find the same row. With suggest set it is also a dropdown: focus it, or press its caret, and the codes that field books against most open before anything is typed.

ui-suggest

For the question that is a pick and a name: the answer is usually one of a handful, occasionally is not one of them at all, and the handful is already in memory. Press or type and the list drops under the box; type past it and what you wrote is the answer, which the panel says rather than leaving you to read an empty list. ui-select when nothing else is allowed, ui-icd10 when the list is seventy thousand rows and has to be searched.

ui-menu · ui-dropdown-menu · ui-breadcrumb

Two list surfaces that look alike and are not the same thing. ui-menu is a list of actions — role="menu", picking one does something. ui-dropdown-menu is a list of choices — role="listbox", picking one changes a value.

Breadcrumb — full, and collapsed at four

ui-command-bar

The field is an ARIA combobox pointed at the results list, so the highlighted command is announced while the caret stays where you are still typing. Arrow keys move the highlight; Enter picks it.

ui-spinner

The indeterminate loader, for a panel waiting on a response. Reach for ui-button[loading] when an action you just took is running, ui-data-table when rows are coming, and ui-progress-bar when you can say how far along it is.

ui-date-picker

Roving tabindex, not a tab stop per day. Arrows move inside the grid, PageUp/PageDown change month, Home/End go to the ends of the week, and stepping past the edge of a month pulls the next one into view.
